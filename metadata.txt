about=A cross-section profiling toolbox for QGIS:
    1. Draw a cross-section line on the canvas, or click to select an existing line feature
    2. Sample one or more DEMs along the line and plot them in an interactive chart
    3. Build a georeferenced profile grid drawn directly on the map canvas

    Includes vector-layer sampling, slope profiles, a chart crosshair with
    cursor-snap, live update while drawing, and table export.
